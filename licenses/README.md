# Included dependency notices

bundled-dependencies/ retains the license files and package metadata for the exact locked dependency closure of Cheerio, crypto-es and @mana-app/types, including both entities versions. INDEX.json identifies their installed package paths and versions. The full crypto-es/CryptoJS notice collection is also retained separately in crypto-es-LICENSE.

boolbase 1.0.0 declares ISC in its published package metadata but omits a standalone license file. boolbase-LICENSE preserves the upstream notice retrieved from https://github.com/fb55/boolbase/blob/master/LICENSE on 2026-10-18.

The Mana builder injects browser polyfills. Their legal banners remain in the unchanged bundle. Complete notices are retained here for buffer, base64-js, ieee754 and base-64. The first three notice texts are copied from locally installed packages (buffer 6.0.3, base64-js 1.5.1, ieee754 1.2.1); these are notice provenance, not a claim that opaque builder-embedded versions were independently resolved. base-64 is identified as version 1.0.0 by its retained bundle banner; its notice is from https://github.com/mathiasbynens/base64/blob/v1.0.0/LICENSE-MIT.txt.
